# Instagram grid — instagram.com/quite_apps

Six 1080x1080 cards, generated by `tools/make-instagram.py`, which imports the
helpers from `tools/make-shots.py`. The grid, the Chrome Web Store screenshots
and the site therefore share one mark, one set of accents and one popup drawing.

Regenerate after changing `data/extensions.json`:

    python3 tools/make-instagram.py

## Posting order

Instagram fills the grid newest first from the top left, so post them in
**reverse**: `6-source` first, `1-family` last. That leaves the family card in
the top-left corner, which is the first thing a visitor's eye lands on.

## What each card is for

| File | Job |
|---|---|
| `1-family` | There are three of these and they are one studio |
| `2-youtube` | What Quite for YouTube does, with its popup |
| `3-facebook` | What Quite for Facebook does, with its popup |
| `4-cookies` | What Quite for Cookies does, with its popup |
| `5-privacy` | No account, no server, nothing sent to us |
| `6-source` | MIT, source public, breakages written up |

## Two constraints that shaped these

A post carries no clickable link, so every card names `quiteapps.co.uk`. On the
three product cards the popup bleeds over the footer, so the domain sits up on
the wordmark row instead.

The counters shown are the real ones from `data/extensions.json`, so they change
when those change. Regenerate rather than editing a PNG, or the artwork and the
site will disagree.
